# turn/turnuserdb.txt Reconnaissance Report

## File Location
`webrtc/turn/turnuserdb.txt`

## Purpose
User database for the TURN server, providing hashed credentials.

## Content
```
# Format: username:hashed_password:expiry
demo:$(openssl passwd -1 demo):never
```

## Configuration Intent
- The README mentions using `turnadmin` or `openssl passwd` to generate hashed passwords.
- This file contains a single user `demo` with a hashed password generated by `openssl passwd -1 demo`.
- The `expiry` field is set to `never`.

## Assumptions / Missing Info
- The `turnuserdb.txt` file is **not** mounted into the `coturn` container by default (volume is commented out in `docker-compose.yaml`).
- If the file is not present inside the container, authentication will fail.

## Observed Behavior
- When the TURN server is started with this file mounted, clients can authenticate using `demo`/`demo`.
